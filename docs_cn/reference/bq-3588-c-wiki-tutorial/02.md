# 产品优势

1.搭载 RK3588 高性能 SOC，集成了四核 Cortex-A76 和四核 Cortex-A55，主频高达 2.4G

2.算力高达 6Tops，支持 INT4/INT8/INT16/FP16 运算，满足大多数人工智能模型的算力需求

3.强大的编解码能力，最高支持 8K@60fps

4.丰富的接口类型，满足行业应用开发需求
