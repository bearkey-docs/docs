# 二、用户与密码

### 1. 默认用户

| 项目 | 默认值 |
| --- | --- |
| 用户名 | `rockchip` |
| 密码 | `rockchip` |

首次登录后，建议根据项目安全要求修改默认密码。

### 2. 获取 root 权限

部分硬件测试需要 root 权限，登录系统后执行：

```shell
sudo su
```

### 3. SSH 登录

开发板接入网络后，可查看 IP 地址：

```shell
ip addr
```

在 PC 端执行：

```shell
ssh rockchip@<开发板IP>
```

如果无法连接 SSH，可在开发板端检查服务：

```shell
sudo systemctl status ssh
```
